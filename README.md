## 📖 About This Course

This repository tracks all coursework for **DATA 201**, covering relational database
architecture from the ground up — from entity-relationship modeling all the way to
query optimization and transaction management.

> **Instructor:** Dr. Guannan Liu · **Schedule:** Thursdays, 6:00–8:45 PM · Room BBC 222

## 🧭 Topics Covered

| # | Topic | Key Concepts |
|---|-------|---------------|
| 1 | Relational DB Fundamentals | Intro to relational databases & MySQL |
| 2 | ER / EER Modeling | Entity-relationship & enhanced ER model |
| 3 | Relational Model | ER → relational mapping, keys, constraints |
| 4 | Normalization | Functional dependency, integrity rules, 1NF–3NF |
| 5 | SQL Basics | DDL/DML, aggregates, `GROUP BY`, NULL semantics |
| 6 | Joins & Subqueries | Join semantics, fan-out traps |
| 7 | Advanced SQL | Window functions, set operations |
| 8 | Transactions | ACID properties, DBMS abstraction layers |
| 9 | Indexing | Hashing, B-trees |
| 10 | Query Optimization | `EXPLAIN`, index usage, query plans |
| 11 | Applied DB | Web application integration |
| 12 | Modern Analytics Stack | Cloud warehouses, columnar storage, JSON/semi-structured data |

## 🏗️ Featured: Group Project

A semester-long project normalizing a real-world dataset with **4+ tables** and
**50,000+ rows**, starting from an un-normalized schema and documenting the
before/after normalization process.

- 📊 **Dataset:** Steam Store Games (Kaggle)
- 🎯 **Goal:** Identify atomicity violations → normalize to 3NF → document the transformation
- 🛠️ **Tools:** GitHub for version control & collaboration tracking
